# サウンド・ミキサー・パーティー
https://chachaneko4649.github.io/SoundMaskGame/
聴覚を頼りに音の正体（ポイント）を当てるパーティーゲームです。

## 遊び方
1. 1人がホストになり、4つの音をランダム生成してミックスします。
2. ホストは「どの音に何ポイント割り振るか」を決めます。
3. プレイヤーは流れてくる音を聞いて、どれが何ポイントの音か口頭で回答します。
4. ホストが正解を確認し、ポイントを配布してターン交代！

## 技術スタック
- HTML5 / CSS3
- JavaScript (Web Audio API)
- Firebase (Cloud Firestore)
