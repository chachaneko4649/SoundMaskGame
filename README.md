# 🔊 サウンド・ミキサー・パーティー (Sound Mixer Party)

スマホのブラウザで手軽に遊べる、聴覚を頼りにしたリアルタイム・パーティーゲームです。

---

## 🎮 ゲームのルール
このゲームは、1人の**ホスト**と複数の**プレイヤー**に分かれて遊びます。

1. **サウンド生成**: ホストが「音を生成」ボタンを押し、4種類の音をミックスします。
2. **ポイント設定**: ホスト側の画面には、各音に対してポイント（1pt, 2pt, 3pt, -2pt）が割り振られています。
3. **音当て**: プレイヤーは流れてくるミックス音を聞き分け、どの音が何ポイントかを予想して口頭で発表します。
4. **ポイント付与**: ホストは正解したプレイヤーに、画面上のボタンでポイントを加算します。
5. **交代**: ターンが終了したらホストが交代し、次のゲームが始まります。

## ✨ 特徴
- **リアルタイム同期**: 誰かがポイントを獲得すると、全員の画面のランキングが即座に更新されます。
- **自動リセット機能**: 最終プレイから10分経過すると、古いデータは自動的にクリアされ、新しいゲームが始められます。
- **インストール不要**: Webブラウザ（ChromeやSafari）があれば、誰でもすぐに参加可能です。

## 🛠 使用技術
- **フロントエンド**: HTML5, CSS3, JavaScript (Web Audio API)
- **バックエンド**: Firebase (Cloud Firestore)

## ⚠️ 注意事項
- ホストが音を鳴らすため、ホストの方はスマホの音量を上げるか、スピーカーに接続してプレイすることをおすすめします。
